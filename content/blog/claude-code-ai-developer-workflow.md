# Claude Code: The AI Coding Agent That Changed How I Build Software

There's a difference between asking an AI to write code and having an AI that actually **works alongside you in your terminal** — reading your files, running commands, catching its own errors, and shipping working software.

That's Claude Code. And after using it daily to build production apps, I've structured everything I've learned into a free course modelled on the official Anthropic Skilljar curriculum.

---

## What Is Claude Code?

Claude Code is Anthropic's official CLI-based AI coding agent. Unlike a chat interface where you paste code back and forth, Claude Code lives in your terminal, has direct access to your project files, and can:

- Read any file in your codebase
- Write and edit code with surgical precision
- Run Bash commands and interpret the output
- Fix bugs it introduces — automatically
- Commit to Git on your behalf

It's not autocomplete. It's an agent that understands your entire project and acts on it.

---

## The Core Workflow: Explore → Plan → Code → Commit

This is the daily workflow I follow — and it's also the structure of the official Anthropic course:

1. **Explore** — ask Claude to map the codebase before touching anything
2. **Plan** — get a written step-by-step approach before any code is written
3. **Code** — natural language edits: "add X", "fix Y", "refactor Z to use pattern W"
4. **Commit** — Claude writes the commit message and pushes to Git

The result: I move from idea to deployed feature in a fraction of the time it used to take.

## CLAUDE.md: Teaching Claude Your Project

The single most powerful thing you can do is create a `CLAUDE.md` file in your project root. It's a plain text file where you tell Claude:

- What stack you're using
- Your coding conventions
- Services and credentials locations
- What NOT to do

Claude reads it at the start of every session. It's like onboarding a new developer — except they never forget anything you told them.

---

## MCP: Connecting Claude to the Real World

Model Context Protocol (MCP) lets Claude Code connect to external services:

- **Gmail MCP** — read and summarise emails in natural language
- **O365 MCP** — access Outlook, Calendar, and OneDrive
- **ServiceNow MCP** — query tickets and check SLA status without logging into a browser
- **Custom MCP** — any REST API can become a Claude tool with a simple Python server

Once connected, you work entirely in the terminal. No browser switching, no copy-pasting from dashboards.
